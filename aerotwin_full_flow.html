Page 1 — Live Dashboard
What a user can do working
Select any aircraft currently flying over Asian airspace from OpenSky. View live altitude, airspeed, RUL prediction, health score, SHAP feature attribution chart, estimated CO₂ and fuel burn, and a live map with flight path polyline. Each metric updates every 15 seconds.
What is missing gaps
No airline/aircraft info shown — just raw callsigns like A6GBA with no context
No alert/warning system — if anomaly_flag fires there is no visual indicator to the user
No refresh button — user has to know Streamlit auto-refreshes every 15s
No historical comparison — can't see if this aircraft is worse than last week
Page 2 — Pakistan Fleet
What a user can do working
Select airline (PIA/AirBlue/AirSial/FlyJinnah) then specific aircraft. View live position (GPS or estimated from route), RUL, health score, SHAP chart, fuel/CO₂ estimates, real weather for nearest airport, aircraft info panel, full airline fleet status table, and maintenance advisory if health is critical.
What is missing gaps
RUL shows 45.2 for most aircraft — LSTM only has 1 telemetry record per plane, not enough for meaningful inference
Airborne/Grounded badge in top right is hardcoded — not reading from fleet_status table yet
No trend chart — can't see how health score changed over past 7 days for this aircraft
AviationStack saving 0 flights recently — need to check API key usage and rate limit
Estimated position notice shows but doesn't say which route it's estimated from
Page 3 — Mission Logs
What a user can do partial
Select a fleet aircraft and view its completed flight history — tail number, origin, destination, fuel consumed, CO₂, health score at landing. Health trend chart. CSV export button. Force-insert test record button for demo.
What is missing gaps
Most aircraft show 0 flights — absence detection is firing but flight_history still not populating reliably
Origin/Destination shows "Unknown" for existing rows — new rows will have real IATA codes going forward
No per-flight detail view — can't click a flight to see detailed telemetry from that specific flight
No pagination — if 100+ flights logged, table will be unreadable
Page 4 — Maintenance Portal
What a user can do working
Select aircraft, view current health/risk/RUL. Select a component (Engine 1/2, APU, Landing Gear, Avionics, Windshield, Fuel System). See last maintenance date, type, location. Log new maintenance with type, location, notes. On submit health resets to 100% instantly. Full maintenance history table shown below.
What is missing gaps
No per-component health degradation — all components show same health, not individual scores
No maintenance schedule prediction — system doesn't tell you when next maintenance is due
No technician authentication — anyone can log maintenance with no credentials
No maintenance cost tracking — industry systems always track labour hours and parts cost
Health resets to 100% immediately — should degrade gradually over subsequent flights
Page 5 — Flight Simulator
What a user can do working
Select aircraft, set departure/arrival airports (12 options including international), aircraft age, cargo weight, weather conditions. Run simulation to get predicted fuel, CO₂, health impact, flight distance, flight time, next maintenance interval, and risk flags.
What is missing gaps
No comparison mode — can't simulate same route with 2 different aircraft to compare efficiency
Fuel calculation is a formula, not ML-based — not using the LSTM model for prediction
No save/export — can't save simulation results for reporting
Critical gaps for FYP jury
Data pipeline reliability
AviationStack saving 0 flights — API key may be exhausted (100 req/month)
flight_history not auto-populating — absence detection needs more testing cycles
Rate limit manager not built yet — no protection against API exhaustion
ML model quality
LSTM shows 45.2 for all aircraft — needs 30 rows per aircraft for proper inference
SHAP values are approximated math, not real TreeExplainer output
sklearn version warning on every startup — could fail silently
Missing for industry grade
No user authentication — any user can access everything
No alert notifications — no email/SMS when aircraft health drops critically
No fleet overview page — can't see all 44 aircraft health at a glance
Demo readiness
Most fleet aircraft show no live data — need seeded realistic telemetry for demo
Weather working but takes 5 min to first appear
Maintenance portal fully functional for demo
